# 回观 · 已验收的节气素材

这些是为遂问生成并在回观试片中评审过的画面素材，不是实时摄影资料。保留确认过的照片质感及透明通道；按最终取景裁去不可见区域，并按界面需要控制部分素材尺寸。大雪与白露沿用验收版本的原始 WebP。没有联网取图。

素材只装饰桌面/浏览器共用的回观。入口使用现有公历节气和统计时段；不参与卦例、判据或记录统计。尚未验收的节气不挂额外素材。

The additional swallows, blossoms, cloudbreak, turning leaf, grass dew,
lotus, heat haze, first ice, icicles and deep-ice textures are repo-local derivatives of the generated imagery used in the approved seasonal
study. The WebPs are lossless alpha crops of the exact reviewed raster assets;
no real record, external image request or dependency is bundled here.
