# 判据从哪来

## 一句话

这个软件怎么起卦、怎么排盘、六宫怎么说、断辞怎么写，全部来自 `apps/shared-judgment/corpus/`
下的九份体系文档（`00_总纲与索引` … `08_依据与讲者分级`，约 23.7 万字）。文档是人读的，
跑 `node tools/gen-corpus.mjs` 之后变成代码里的 `src/corpus.js`。

想换一套判据、改成你自己的理解，改 md 再重跑一次就行，没有任何地方会拦你。

## 数据怎么流动

```
apps/shared-judgment/corpus/00…08.md     ← 人读的真源（Markdown，九份）
   └─ node tools/gen-corpus.mjs ─→ src/corpus.js        ← 打包成 JS，代码读这个
        ├─ src/prompt.js     SYS：解卦用的系统提示词
        ├─ src/judgment.js   判据正文：G 六宫固定层 / COMMON 通用 / YQ 应期 / CATS 事类 / buildBlocks 断卦块
        ├─ src/asks.js · asks-more.js   本机速断的按问法素材（{ plain, tx, src }）
        └─ src/mcp-tools.js  MCP 工具表与执行（判据从这里取，不另存一份）
```

- **改判据只改 corpus 里的 md**，然后重跑 `gen-corpus.mjs`；`src/corpus.js` 是产物，别手改。
- 每条判据的出处写成 `corpus/0X §N`（`N` = 语料里的小节号），界面上「出处：…」显示的就是它。
- 算法部分（走宫 `cast.js`、历法、五行生克、体用计算）不是判据文本，改不改随你。
- 安卓与 iOS 不吃 `corpus.js`：判据是 Kotlin 移植（`apps/android/kuikly/shared/.../judge/`），
  系统提示词由 `node apps/android/scripts/gen-prompt.mjs` 从 `src/prompt.js` 生成。

## 语料里的分级与口径

`08` 里给每条材料标了级别：**A**＝讲者本人的亲笔或亲口，B＝入门弟子转述（要标「弟子转述」），
C＝学员整理或存疑（只作参考，不当规则用）。语料里每一处引文都能按这个级别回查到材料。

有些事材料本身给了两种说法，或者干脆没写。这类地方不在语料里「补」，而是在 `08` 末尾单独登记成
**口径**（写明「材料原文之外」），代码与提示词都按登记的口径走。举几处：

| 事 | 口径 |
|---|---|
| 生男生女 | 大安 · 空亡 · 小吉＝男；速喜 · 留连 · 赤口＝女；**大安 · 小吉 · 留连另有女性几率**（可翻，不死断） |
| 天气 | 问「会不会下雨／下雪」只答会不会＋一句理由；问「天气如何」才描述天气 |
| 取数见 0 | **0 取 10** |
| 藏干 | **用的少**；取象和转太极点可能要用到 |
| 体用 | **体＝落宫，用＝起卦时辰**（材料只说「人宫跟体用有关系」，没写成定义） |

## 提示词与语料是对齐的

`src/prompt.js` 的 SYS（安卓是 `judge/PromptData.kt`）写的就是上面这些口径：

| 项 | 提示词写的是 |
|---|---|
| 体用 | 体＝落宫，用＝起卦时辰；只在结果不明、还有后续、事复杂时才看 |
| 藏干 | 用的少；日常断以六宫宫义为主线，取象、转太极点时按藏干表取 |
| 天气应期 | 只到时辰；问会不会只答会不会，问天气如何才描述；温度两说不硬套 |
| 取数 | 先吉凶后数字；数不许直接当公历年 |

改提示词只需改 `src/prompt.js`，改完重跑前端构建；安卓再跑一次 `gen-prompt.mjs`。

## 自己验一下

```bash
node tools/gen-corpus.mjs                 # 语料 → src/corpus.js（改了 md 就跑这个）
cd apps/desktop-web && npm run build      # 桌面端单文件
```
